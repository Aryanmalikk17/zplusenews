## 🔗 Internal Link Matrix Rules

1. **Bidirectional Hub Links:** Every Spoke page MUST link to the Pillar page (`https://www.zplusenews.com`) using keywords like "breaking news India" or "live India news", and the Pillar page MUST link back to every Spoke.
2. **Cluster Siloing:** Spoke pages in the same cluster must link to each other (e.g. *Latest Politics News India* links to *Indian Polity News* and *Elections in India live updates*).
3. **Anchor Text Variety:** Use exact or near-match semantic terms for anchor text. Avoid generic text like "read more" or "click here".
